# Discord Upload Steps

Discord soundboard uploads are done through the desktop app or browser.

## Fast Start

1. Open Discord on desktop or browser.
2. Go to the server you want.
3. Open **Server Settings > Soundboard**.
4. Choose **Upload Sound**.
5. Browse to `discord-upload-queue` for the first 8 recommended clips, or `discord-ready-mp3` for all 40.
6. Add a short name and emoji for each clip, then upload.

## Recommended First 8

- `skill_issue.mp3`
- `absolutely_not.mp3`
- `bro_is_lost.mp3`
- `delete_that.mp3`
- `caught_in_4k.mp3`
- `fake_ping.mp3`
- `metal_bonk.mp3`
- `dramatic_boom.mp3`

## Requirements Checked

- Format: MP3
- Length: under 5 seconds
- Size: under 512 KB
- Permission needed: Create Expressions
